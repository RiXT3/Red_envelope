# Red Envelope PCB

A decorative twolayer PCB inspired by traditional Chinese red envelopes and the Mid Autumn Festival

### PCB Specifications
- **Layers:** 2
- **Top layer:** Custom PCB-art
- **Bottom layer:** Blank - available for yor customization

### Recommended PCB Finish
For the best result I recommend:
- **Solder mask:** Red
- **Surface finish:** ENIG (Electroless Nickel Immersion Gold)

*ENIG can significantly increase manufacturing costs compared to standard HASL finishes.*
